# Privacy — OpenClaw New P0 open-source component

This component communicates over authenticated local Windows named pipes
and stores operation/audit information only under the locally configured
installation. It implements no analytics, cloud telemetry, advertisements
or automatic outbound network transfer.

The source excludes user records, credentials, production files and
remote endpoints. No other OpenClaw New modules are included.

Software installation and Windows configuration changes require an
authorized operator. This alpha release is not production certified.
